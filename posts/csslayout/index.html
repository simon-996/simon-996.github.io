html-css-7-布局概述

发表于2026-05-18|更新于2026-05-18|课件
|浏览量:

🎯 学习目标

  1. 理解 CSS 布局的作用和基本思路。
  2. 掌握普通文档流、Flex、Grid、定位、浮动等布局方式的适用场景。
  3. 能区分一维布局和二维布局。
  4. 理解盒子模型、元素显示模式与布局之间的关系。
  5. 能根据页面需求选择合适的布局方式。
  6. 初步建立从结构到布局的页面开发流程。

什么是 CSS 布局？

CSS 布局用于控制页面元素的位置、尺寸、排列方向、对齐方式和空间分配。

网页不是把内容简单堆在页面上，而是要根据设计需求组织结构。例如：

  • 标题、正文、图片如何上下排列
  • 导航栏中的 logo 和菜单如何左右分布
  • 侧边栏和主要内容如何形成两栏结构
  • 多个卡片如何自动换行
  • 页面在电脑、平板、手机上如何适配

布局的核心目标是：让页面结构清晰、内容排列稳定，并能适应不同屏幕尺寸。

页面开发的常见顺序：

  1. 先分析页面有哪些内容区域。
  2. 用 HTML 写出清晰的结构。
  3. 再用 CSS 控制区域大小、排列和间距。
  4. 最后处理颜色、字体、边框、阴影等视觉样式。

普通文档流

普通文档流是浏览器默认的排列方式。

默认情况下：

  • 块级元素从上到下排列。
  • 行内元素在一行内从左到右排列。
  • 元素会按照 HTML 中出现的顺序显示。

上面的内容会自然上下排列，不需要额外布局代码。

适合普通文档流的场景：

  • 文章内容
  • 表单项目
  • 简单上下排列的页面模块
  • 标题、段落、列表等内容结构

普通文档流是所有布局的基础。不是所有页面都需要复杂布局，能用默认排列解决时，就不要过度设计。

常用 CSS 布局方式

实际开发中，常见布局方式包括普通文档流、Flex、Grid、定位、浮动和表格布局。

布局方式 适用场景 优点 注意点
普通文档流 文章、表单、简单页面 简单自然，符合 HTML 默认规则 不适合复杂对齐和分栏
Flex 弹性布局 导航栏、按钮组、卡片列表、居中布局 对齐方便，适合一行或一列的一维布局 不适合复杂二维网格
Grid 网格布局 页面整体结构、仪表盘、图片墙 可以同时控制行和列，适合二维布局 学习成本比 Flex 略高
Position 定位 弹窗、角标、固定导航、悬浮按钮 可以精确控制元素位置 脱离文档流后容易重叠
Float 浮动 图文环绕、旧项目维护 可以实现文字环绕 做页面布局时已经不推荐
Table 表格布局 表格数据展示 行列对齐稳定 不推荐用于页面结构布局

一维布局和二维布局

选择 Flex 还是 Grid，关键看布局是“一维”还是“二维”。

一维布局

一维布局只主要关心一个方向：一行或一列。

这种场景只需要控制链接横向排列，所以适合 Flex。

二维布局

二维布局同时关心行和列。

例如卡片网格：

这种场景需要同时控制列数、行距、列距，所以适合 Grid。

布局选择原则

可以按照下面的思路选择布局方式：

  1. 内容自然上下排列：使用普通文档流。
  2. 一行或一列内部排列：优先使用 Flex。
  3. 同时控制多行和多列：优先使用 Grid。
  4. 需要覆盖、固定、悬浮：使用 Position。
  5. 需要文字环绕图片：可以使用 Float。
  6. 展示真实表格数据：使用 <table>。

display 与布局

display 决定元素以什么方式参与布局。

常见值：

属性值 作用
block 块级显示，独占一行
inline 行内显示，不独占一行
inline-block 行内排列，同时可以设置宽高
none 隐藏元素，不占空间
flex 创建弹性容器
grid 创建网格容器

Position 定位概述

定位用于把元素放到特定位置。

常见值：

属性值 说明
static 默认值，按照普通文档流排列
relative 相对自身原位置偏移
absolute 相对最近的定位祖先元素定位
fixed 相对浏览器窗口固定定位
sticky 滚动到指定位置后吸附

示例：右上角角标。

定位很适合做角标、弹窗、遮罩、固定导航等效果，但不适合作为普通页面大结构的主要布局方式。

Float 浮动概述

浮动最早常被用来做多栏布局，但现在页面布局通常使用 Flex 或 Grid。

浮动现在最典型的用途是图文环绕：

  • 知道旧项目中可能会遇到它。
  • 理解它会影响后续元素。
  • 新页面的大结构布局优先考虑 Flex 和 Grid。

总结

  1. CSS 布局用于控制元素的位置、尺寸、排列和空间分配。
  2. 普通文档流是页面布局的基础。
  3. Flex 适合一维布局，常用于导航、按钮组、居中和组件内部排列。
  4. Grid 适合二维布局，常用于页面区域划分和卡片网格。
  5. Position 适合覆盖、固定、悬浮和精确定位。
  6. Float 主要用于图文环绕和旧项目维护。
  7. 开发布局时应先分析 HTML 结构，再选择合适的 CSS 布局方式。
