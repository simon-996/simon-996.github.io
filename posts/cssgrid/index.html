html-css-9-Grid网格布局

发表于2026-06-01|更新于2026-05-18|课件
|浏览量:

🎯 学习目标

  1. 理解 Grid 网格布局的作用和适用场景。
  2. 掌握网格容器、网格项目、行、列、间距等基本概念。
  3. 熟练使用 display: grid 创建网格容器。
  4. 掌握 grid-template-columns 和 grid-template-rows 定义行列。
  5. 理解 fr、repeat()、minmax() 等常见写法。
  6. 掌握 gap、grid-column、grid-row 等常用属性。
  7. 能使用 Grid 完成卡片网格、页面分区和响应式布局。

什么是 Grid 布局？

Grid 是 CSS 中的二维布局方式。

Flex 更适合处理一行或一列，而 Grid 可以同时控制行和列。

适合 Grid 的场景：

  • 商品列表
  • 图片墙
  • 课程卡片列表
  • 仪表盘页面
  • 页面整体区域划分
  • 需要同时控制行和列的复杂布局

Grid 基本结构

Grid 布局由两部分组成：

  • 网格容器：设置了 display: grid 的父元素。
  • 网格项目：网格容器中的直接子元素。

只设置 display: grid 后，项目仍然会默认按一列排列。要形成多列，需要继续定义列。

auto-fit 和 auto-fill

auto-fit 可以让浏览器根据容器宽度自动决定列数。

效果：

  • 容器宽时，一行显示更多列。
  • 容器窄时，自动减少列数。
  • 每列最小宽度为 180px。

这是实际开发中很常用的响应式卡片写法。

控制项目跨行：grid-row

grid-row 可以让某个项目纵向跨多行。

常用于不规则卡片、仪表盘模块、图片墙布局。

grid-template-areas 区域命名

复杂页面可以使用区域命名，让结构更直观。

区域命名适合页面大结构，优点是可读性强。

对齐方式

Grid 中也可以控制对齐。

justify-items

控制项目在单元格内的水平方向对齐。

align-items

控制项目在单元格内的垂直方向对齐。

place-items

place-items 是 align-items 和 justify-items 的简写。

可以让项目在单元格内水平垂直居中。

Grid 和 Flex 怎么选？

需求 推荐
导航链接横向排列 Flex
按钮组左右排列 Flex
单个卡片内部上下左右对齐 Flex
多列卡片列表 Grid
图片墙 Grid
页面整体分区 Grid
一边固定宽度，一边自适应 Flex 或 Grid 都可以

简单记忆：

  • 只关心一个方向：Flex。
  • 同时关心行和列：Grid。

总结

  1. Grid 是二维布局方式，可以同时控制行和列。
  2. 父元素设置 display: grid 后，直接子元素成为网格项目。
  3. grid-template-columns 定义列，grid-template-rows 定义行。
  4. fr 表示按份数分配剩余空间。
  5. repeat() 可以简化重复列或行的写法。
  6. minmax()、auto-fit 常用于响应式网格。
  7. grid-column 和 grid-row 可以控制项目跨列、跨行。
  8. 页面大结构和卡片网格通常更适合使用 Grid。
