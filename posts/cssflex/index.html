🎯 学习目标

  1. 理解 CSS 布局的作用和常见布局方式。
  2. 理解弹性盒子 Flex 布局的作用与基本概念。
  3. 掌握主轴、交叉轴、容器、项目四个核心术语。
  4. 熟练使用 display: flex 创建弹性容器。
  5. 掌握 flex-direction、justify-content、align-items 等常用容器属性。
  6. 理解 flex-wrap 与 gap 在多行布局中的作用。
  7. 掌握 flex、order、align-self 等弹性项目属性。
  8. 能根据页面需求选择合适的布局方式。
  9. 能使用 Flex 独立完成导航栏、卡片列表、水平垂直居中等常见布局。

CSS 布局的作用

CSS 布局用于控制页面元素的位置、尺寸、排列方向、对齐方式和空间分配。

网页不是把内容简单堆在页面上，而是要根据设计需求组织结构。例如：

  • 标题、正文、图片如何上下排列
  • 导航栏中的 logo 和菜单如何左右分布
  • 侧边栏和主要内容如何形成两栏布局
  • 多个卡片如何自动换行
  • 页面在电脑、平板、手机上如何适配

因此，布局的核心目标是：让页面结构清晰、内容排列稳定，并能适应不同屏幕尺寸。

常用 CSS 布局方式

实际开发中，常见布局方式包括普通文档流、Flex、Grid、浮动、定位和表格布局。

布局方式 适用场景 优点 缺点
普通文档流 文章、表单、简单页面 简单自然，符合 HTML 默认排列规则 不适合复杂对齐和分栏
Flex 弹性布局 导航栏、按钮组、卡片列表、居中布局 对齐方便，适合一行或一列的一维布局，响应式友好 不适合复杂二维网格
Grid 网格布局 页面整体结构、仪表盘、图片墙 可以同时控制行和列，适合二维布局 学习成本比 Flex 略高
Float 浮动布局 图文环绕、旧项目维护 可以实现文字环绕 容易影响后续元素，需要清除浮动
Position 定位布局 弹窗、角标、固定导航、悬浮按钮 可以精确控制元素位置 脱离文档流后容易遮挡或重叠
Table 表格布局 表格数据展示 行列对齐稳定 不推荐用于页面结构布局，语义不合适

简单选择原则：

  • 内容自然上下排列：优先使用普通文档流。
  • 一行或一列内部排列：优先使用 Flex。
  • 同时控制多行和多列：优先使用 Grid。
  • 需要悬浮、覆盖、固定位置：使用 Position。
  • 文字环绕图片或维护旧页面：可能会遇到 Float。

什么是 Flex 布局？

Flex 是 Flexible Box 的缩写，中文常叫弹性盒子。

它是一种 CSS 布局方式，专门用来处理一维布局：

  • 一行中的多个元素如何排列
  • 一列中的多个元素如何分布
  • 元素之间如何对齐
  • 剩余空间如何分配
  • 屏幕变窄时元素如何换行

传统布局常依赖 float、inline-block、margin 等方式，写起来容易出现对齐困难、间距难控、清除浮动等问题。Flex 的优势是：只要把父元素设为弹性容器，子元素就能按照规则自动排列。

Flex 布局的特点

Flex 主要解决“一维布局”问题，也就是一行或一列中的排列问题。

常见能力：

  • 控制排列方向：横向排列或纵向排列。
  • 控制对齐方式：主轴对齐、交叉轴对齐。
  • 控制剩余空间：让项目自动放大或缩小。
  • 控制项目换行：空间不足时自动换到下一行。
  • 控制项目顺序：在不改 HTML 结构的情况下调整显示顺序。

Flex 的优点：

  1. 写法简洁，特别适合水平垂直居中。
  2. 对齐能力强，能轻松实现左对齐、右对齐、居中、两端对齐。
  3. 子元素可以自动伸缩，适合响应式页面。
  4. 可以使用 gap 设置项目间距，比给每个项目写 margin 更清晰。
  5. 很适合组件内部布局，例如导航栏、工具栏、按钮组、卡片内容。

Flex 的局限：

  1. Flex 更适合一维布局，不适合复杂的二维网格。
  2. 多行布局时，对行和列的整体控制不如 Grid 精确。
  3. 子元素宽度、缩放比例设置不当时，可能出现挤压或溢出。
  4. order 能改变视觉顺序，但 HTML 结构顺序不变，过度使用可能影响阅读顺序和可访问性。

主轴与交叉轴

理解 Flex，最重要的是理解两条轴：

  • 主轴：弹性项目主要排列的方向。
  • 交叉轴：与主轴垂直的方向。

默认情况下：

  • 主轴是水平方向，从左到右。
  • 交叉轴是垂直方向，从上到下。

默认效果：子元素会从左到右排成一行。

注意：主轴不一定永远是水平的，它会被 flex-direction 改变。

容器属性

容器属性写在父元素上，用来控制所有弹性项目的整体排列方式。

display: flex

创建弹性容器。

设置后，容器中的直接子元素会默认横向排列。

flex-direction 主轴方向

flex-direction 用来决定主轴方向，也就是项目按照哪个方向排列。

属性值 说明
row 默认值，从左到右排列
row-reverse 从右到左排列
column 从上到下排列
column-reverse 从下到上排列

记忆方式：

  • row 是行，横向排列。
  • column 是列，纵向排列。

justify-content 主轴对齐

justify-content 控制项目在主轴方向上的对齐方式。

space-around 每个项目左右间距相等
space-evenly 所有空白间距完全相等

项目属性写在弹性项目上，用来控制某一个子元素自己的表现。

如果主轴是横向，flex-basis 类似宽度；如果主轴是纵向，flex-basis 类似高度。

flex-direction 改变后的对齐判断

很多同学会把 justify-content 理解成“水平对齐”，把 align-items 理解成“垂直对齐”，这是错误的。

正确理解：

  • justify-content 永远控制主轴。
  • align-items 永远控制交叉轴。

当 flex-direction: row 时：

  • 主轴是水平的，justify-content 控制水平。
  • 交叉轴是垂直的，align-items 控制垂直。

当 flex-direction: column 时：

  • 主轴是垂直的，justify-content 控制垂直。
  • 交叉轴是水平的，align-items 控制水平。

开发易错点总结

  1. 忘记设置 display: flex：只有父元素成为弹性容器，Flex 属性才会生效。
  2. 主轴判断错误：justify-content 不等于水平对齐，它控制主轴。
  3. 交叉轴判断错误：align-items 不等于垂直对齐，它控制交叉轴。
  4. 把属性写错位置：容器属性写父元素，项目属性写子元素。
  5. 多行布局忘记 flex-wrap：不设置 flex-wrap: wrap 时，项目会尽量挤在同一行。
  6. 乱用 margin 控制间距：Flex 项目之间的固定间距优先考虑 gap。
  7. flex 简写不理解：flex: 1 不是固定宽度，而是让项目自动分配剩余空间。

总结

  1. Flex 布局核心：父元素设置 display: flex，直接子元素成为弹性项目。
  2. 两条轴：主轴由 flex-direction 决定，交叉轴与主轴垂直。
  3. 主轴对齐：justify-content 控制主轴方向的排列。
  4. 交叉轴对齐：align-items 控制交叉轴方向的排列。
  5. 多行布局：flex-wrap 控制换行，align-content 控制多行整体分布。
  6. 项目伸缩：flex-grow、flex-shrink、flex-basis 可用 flex 简写。
  7. 常见场景：导航栏、水平垂直居中、卡片列表、左右两栏布局都适合使用 Flex。
