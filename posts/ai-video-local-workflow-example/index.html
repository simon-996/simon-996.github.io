零基础学AI视频（四）：从项目素材到本地生成，一个镜头怎么做？

上一篇我们认识了 ComfyUI 和 Pika H3 Flex 的本地参考图生成视频流程：上传图片、输入文字，尝试生成一条视频。

如果我已经有了人物图片和场景图片，希望视频中的人物、环境和构图都参考这些素材，又该怎么办？

这篇文章结合我的《全球学历含金量下降100倍》项目，从剧本、分镜和角色资产讲起，再拆解第一个镜头：素材怎么准备、工作流做什么、生成后如何检查和剪辑。

这篇展示的是项目中的单镜工作流及素材组织方法，下面的参考图用于说明素材分工。工作流文件目前没有随博客提供下载；读者可以用自己的图片，按照同样思路练习。文中所述版本已做静态核对，尚未在目标 ComfyUI 环境完成该版本的视频生成验证，实际画面、声音和节点兼容性仍需检查。

一、先准备剧本和分镜

制作视频之前，先想清楚要讲什么故事。剧本主要写人物、场景、动作和台词；分镜则把剧本拆成一条条可以制作的镜头，补充画面、构图、时长、声音和参考素材。

这个项目的故事从新闻主播播报学历贬值开始，随后展现马浩然确认自己的学校、参加面试，以及公司人员的反应。制作稿进一步拆成 52 条独立镜头任务，并为每一镜整理了建议取用时长、生成请求时长、动作、台词和图片输入。生成时往往要留出余量，实际成片仍需根据画面和声音剪辑。

文末附有项目的完整剧本和完整分镜制作稿，可以先看下方的首镜例子，再对照全文理解每个镜头是怎么从故事变成生成任务的。文末保留的是项目制作记录，其中的时长是当时的预估，素材路径和修订说明对应原项目环境。

三、这次想做一个什么镜头？

项目的开场是一位新闻主播坐在演播室里，向观众播报一条消息。这里选用的是 01A 镜：

女主播正对镜头坐在演播桌后，双手自然放在桌面，以严肃、专业的语气说：“全球学历含金量下降100倍。”

拍摄要求是正面、平视、中景、固定机位：主播的脸、双手和桌子的边缘都要看得见。

如果只把这句话交给模型，主播和演播室的样子仍由模型自行生成。为了让画面更接近项目设计，我为这个镜头准备了三张参考图。

项目同时还准备过调用 Token01 的 API 工作流。它通过远程服务生成，与这里讨论的本地模型工作流是两条不同路径，不能把 API 测试结果直接当成本地模型的验证结果。

七、这个镜头设置了多少时长和画幅？

以项目中现有的 01A 单镜画布为例：

  • 画幅：16:9 横屏。
  • 单镜工作流分辨率设置：0.4 百万像素；具体宽高由工作流中的分辨率节点计算。
  • 时长输入：5 秒。
  • 参考图：主播、演播室、构图图，按上文的 1、2、3 顺序输入。
  • 保存前缀：video/mhr-all/mhr-01A，实际输出目录取决于 ComfyUI 的配置。

项目工作流使用 24 帧/秒，并将请求时长对齐到模型支持的帧数：5 秒请求在当前表达式下对应 124 帧，约 5.17 秒。因此，请求 5 秒不一定得到恰好 5 秒的文件；需要精确时长时，还要检查实际输出并在剪辑中处理。

项目也有多镜整合画布，但第一次运行建议先验证一个镜头：确认模型和节点正常、参考图确实生效，再考虑扩展到其他镜头。

八、生成之后检查什么？

本地工作流运行完成，不等于镜头已经可以使用。拿到结果后，可以按这张清单检查：

  1. 人物：是否只有一位主播？脸、眼镜和服装是否符合参考图？
  2. 场景和构图：演播室是否合理？脸、双手和桌面是否都在画面里？
  3. 动作和镜头：主播是否保持正对镜头？固定机位有没有意外移动？
  4. 声音：中文对白是否完整、清楚，音色是否接近要求？有没有额外说话声？
  5. 时长：实际文件多长？对白有没有被截断？是否需要裁切？

如果发现问题，先确认素材和连接是否正确，再针对最明显的问题调整提示词或参考图。保存每次尝试的参数和结果，方便比较。

上面的清单是验收方法，不是对该版本生成结果的宣称。项目文件记录了静态核对结果，但该本地工作流版本仍需实际生成样片，才能判断参考图、声音和动作是否达到要求。

九、从一个镜头到更多镜头

当一个镜头跑通后，可以沿用同样的方法准备下一镜：换成对应角色和场景，更新参考图顺序、提示词、时长与输出名称，再单独验收。项目中的整合画布能够组织多个生成任务，但不会自动把所有结果剪成成片。

为了组织项目中的全部镜头，我让 AI 根据已有素材和镜头资料协助制作了多镜工作流。下图展示的是这张整合画布的一部分：多组镜头节点连接到共享的模型等配置，每组保留各自的参考素材、提示词和输出节点。

画布中的节点和连线展示了工作流的组织方式，不代表截图中的所有镜头已经生成或验收通过。整合画布的运行兼容性和生成结果仍需逐镜检查。

先把一个镜头的输入、生成和检查走通，再逐步增加数量，遇到问题时也更容易知道是素材、提示词、工作流还是模型设置需要调整。

十、最后把镜头剪成完整视频

生成完各个镜头后，还需要把它们放进剪辑软件，按照故事顺序拼接。下面是这个项目在剪映中的剪辑界面：上方是导入的镜头素材，中间是预览画面，下方的时间线上排列着视频片段和声音素材。

第一次剪辑可以按下面的顺序尝试：

  1. 导入和排列镜头：把生成好的视频导入剪映，按照分镜顺序拖到时间线上，先粗略拼成完整故事。
  2. 逐个检查画面：播放每个片段，留意人物、手部、道具和背景有没有变化或穿帮，以及动作、表情和台词是否自然。
  3. 分割并裁剪：在问题片段的前后分割，删除穿帮、停顿过长或效果不好的部分，再调整相邻镜头的衔接。如果关键动作或对白无法保留，就回到生成步骤重新制作这个镜头。
  4. 处理声音和节奏：检查对白是否完整、画面与声音是否对得上，再按需要添加背景音乐或音效，并调整音量，避免盖住对白。
  5. 完整播放后导出：从头到尾检查故事是否连贯、转场是否自然，以及开头和结尾是否合适，确认后再导出成片。

剪辑可以去掉局部不理想的画面，也能调整叙事节奏；但它不能解决所有生成问题。有些镜头需要重新生成，直到画面和声音足够适合拼进成片。
