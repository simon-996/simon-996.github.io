html-css-2-编辑器安装

发表于2026-03-06|更新于2026-11-21|课件
|浏览量:

上节课用记事本做出了网页，为什么还要学编辑器？

在上一课《网页基本结构标签》中，我们用记事本编写 index.html，用浏览器查看页面。HTML 是纯文本，记事本足以完成这一步。

试着在记事本里给个人介绍页加一段文字。你需要找到 </body> 的位置，写好一对 <p> 和 </p>，再手动对齐缩进。代码变多以后，找标签、补结束标签和整理缩进都会花更多时间。这节课用 Visual Studio Code（简称 VS Code）继续编辑同一个文件，体验它的语法高亮、标签补全和格式化。

在 Windows 上安装 VS Code

  1. 打开 VS Code 官方下载页，在 Windows 区域选择与你的电脑架构对应的用户安装包（User Installer）。
  2. 双击下载的安装程序，按提示完成安装，然后打开 VS Code。 Windows 安装指南
  3. 在 VS Code 中选择「文件 → 打开文件夹」（File → Open Folder），选中上一课创建的 web-practice 文件夹。
  4. 在左侧资源管理器中点击 index.html。此时应该能看到上一课写下的个人介绍。

继续编辑你的网页

  1. 看语法高亮。 找到 <title>、<h1> 和 </body>，观察标签和正文的颜色。
  2. 试标签补全。 在 </body> 前另起一行，输入 <p>，观察 VS Code 自动补出的 </p>。在两个标签之间写一句「我正在学习制作网页」。
  3. 试格式化。 先删掉新增段落开头的缩进，再按 Shift + Alt + F，或在编辑区右键选择「格式化文档」（Format Document）。观察段落的缩进如何重新对齐。
  4. 保存并预览。 按 Ctrl + S 保存，回到上一课打开的浏览器页面按 F5。也可以在 Windows 文件资源管理器中重新打开 index.html。看到新段落，就确认了编辑器里保存的内容已经反映到网页上。

这三项编辑功能是 VS Code 自带的。如果想在每次保存时自动格式化，可以在设置里搜索并勾选「Editor: Format On Save」。 VS Code 的 HTML 功能 · 保存时格式化设置

选学工具

  • Live Server 可以在保存后自动刷新浏览器。在 VS Code 左侧「扩展」中搜索并安装 Ritwick Dey 发布的 Live Server，然后右键 index.html，选择「Open with Live Server」。在新打开的浏览器页面里观察保存后的变化。 Live Server 扩展
  • Open in Browser 可以从编辑器的右键菜单打开浏览器。Auto Rename Tag 可以在修改开始标签时同步修改结束标签。Prettier 可以作为可选的代码格式化工具。
  • HBuilderX 也是一种支持网页开发的编辑器。课程演示和快捷键以 VS Code 为准。
