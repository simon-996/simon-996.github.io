零基础学AI视频（五）：整理素材，让Agent通过中转站生成视频

Token01 注册链接：点击注册

前两篇介绍了如何在本地准备视频模型和参考素材。本地生成需要电脑提供算力，如果显卡暂时带不动，还可以通过网络调用视频生成服务。

这篇结合《全球学历含金量下降100倍》项目中的素材，以 Token01（豆比特）+ Codex Agent + tk01-video-gen 技能为例，梳理从整理图片、安装技能，到提交和检查一个视频任务的过程。

本文根据项目资料、已安装技能的说明和 Token01 视频技能文档整理。服务支持的模型、参数、价格和技能安装包可能发生变化，操作时以官方最新页面和实际账户权限为准。示例中的素材名称是项目案例；项目图片未随本文提供下载。

一、中转站是什么？和本地生成有什么区别？

这里说的中转站，是指提供统一 API（应用程序接口）的服务：你把提示词和参考素材提交给服务，它再通过可用的模型或渠道处理请求，并返回任务状态和视频结果。

Agent 和视频模型不是一回事：Codex 是这里帮助我们整理、调用工具的助手；视频模型由生成请求中的模型名称决定。

三、让 Agent 安装视频生成技能

Skill（技能）可以理解为一套可复用的操作说明，有的还包含脚本和参考文档。Agent 使用相应技能时，可以按这套说明组织请求、提交任务、查询和下载结果。

本例使用的 tk01-video-gen 是 Token01 的视频技能，不是 Codex 自带的视频模型。Codex 技能的一般概念可以参考 OpenAI 的技能说明。

1. 获取技能包

打开 Token01 生视频技能文档，从页面上的下载入口获取 ZIP 技能包。先查看来源和版本，再在自己的电脑上保存文件。下载入口和版本以该页面当时展示的内容为准。

2. 把安装任务交给 Agent

在 Codex 对话中附上技能包，或者提供它在本机的真实路径，并说明：

这里要提供真实 ZIP 文件或路径，不是只输入技能名字就能保证找到。技能里除了 SKILL.md，还可能有脚本和参考资料，安装时需要保留完整目录。Agent 如果提示技能已存在，应先核对版本和来源，不要盲目重复安装。

Token01 文档介绍了将 ZIP 交给 Codex 或 Claude 安装；不同 Agent 的安装界面和目录可能不同。如果安装后当前会话看不到技能，可以新开会话，再让 Agent 确认是否能够使用 tk01-video-gen。

四、配置中转站和 API Key

Token01 的视频技能文档列出两种读取方式：环境变量 TK01_API_KEY，或者用户目录下的密钥文件。以 Windows 密钥文件为例：

在自己的电脑上创建 .tk01-video-gen 文件夹，再创建 api_key.txt，只在文件中填写密钥并保存。Agent 在执行脚本的环境中需要能读取该文件；远程执行环境和本机可能不是同一个目录。其他系统和最新配置方式见官方视频技能说明。

开始前还需要到平台查看余额、令牌分组、模型是否可用、参考素材限制和当前费用。调用 Agent 的对话费用与视频服务收费也可能分别计算，具体以各服务账单为准。

六、提交后发生了什么？

以已安装的 tk01-video-gen 技能为例，流程大致是：

  1. Agent 检查素材、模型和参数，并按平台要求上传需要的文件。
  2. 脚本提交一次生成请求，保存任务 ID 和任务记录。
  3. 脚本查询状态；查询接口响应成功，不等于视频任务已经成功。
  4. 任务成功后，通过平台支持的下载接口获取视频，并保存到本机。
  5. 打开视频检查画面、声音及实际时长。

素材上传产生的临时地址可能包含签名信息，应当按私密信息处理，不要复制到公开文章或共享文件。平台与模型服务方对素材的处理规则，以各自条款为准。

任务很久没完成，能再点一次吗？

不要在状态不明时反复提交。已有任务 ID 或任务记录时，可以让 Agent：

如果提交超时且没有收到任务 ID，先检查平台任务记录和消费记录，再决定是否需要重新提交。等待超时、停止本地程序或关闭界面，不一定代表远程任务被取消或自动退款。

七、结合项目：从单镜到多个镜头

项目中除了本地 ComfyUI 工作流，也准备了通过 Token01 调用远程服务的工作流和镜头清单，用来整理各镜提示词、参考图顺序、时长和任务记录。

对新手来说，建议先完成并检查一个镜头：

  • 素材：人物、场景和构图是否对得上？
  • 视频：人物是否稳定，镜头和动作是否符合要求？
  • 声音：对白是否完整清楚，有没有多余声音？
  • 记录：模型、请求时长、任务 ID、实际文件时长和费用是否清楚？

单镜验证后，再整理其他镜头。远程 API 任务和本地模型工作流属于不同路径；项目里的某种渠道是否支持多图、音频或视频参考，不能直接套用到所有渠道。

八、常见问题

Agent 找不到技能？

先确认安装目录里有完整的 tk01-video-gen 目录和 SKILL.md，再新开会话并确认技能是否可用。安装位置和发现方式随 Agent 环境而异，不要只把一个脚本复制过去。

模型名称存在，为什么还是不能生成？

模型列表中的名称不等于当前令牌和分组一定有权限，也不代表它支持所有素材组合。检查余额、权限、模型名和对应接口的参数要求。

图片上传成功了，为什么生成仍报错？

上传成功只说明素材已传到服务端，不代表所选模型支持这种图片用途或数量。检查参考图、首帧和尾帧参数，以及当前渠道的限制。

本地已经安装了 Pika H3 Flex，可以直接用同一个模型名调用吗？

不一定。本地使用的 Pika H3 Flex 工作流、远程服务中的模型名称和渠道配置可能不同；远程请求应使用服务实际提供的精确模型名，不能因为本地有某个 LoRA 就假定中转站有同名模型。

通过 Agent 调用视频服务，关键仍是把素材、用途、模型、规格和验收标准说清楚。先跑通一个镜头，再扩展到更多任务，会更容易发现问题，也更容易控制费用。
