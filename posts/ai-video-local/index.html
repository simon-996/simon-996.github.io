零基础学AI视频（三）：本地部署Pika H3 Flex，生成第一条视频

在第一篇文章里，我们描述了一只猫：

一只橘猫穿着深蓝色西装，坐在办公室的椅子上，认真地看着桌上的文件。阳光从窗户照进来，镜头缓慢推近。

这一次，我们准备一张橘猫图和一张办公室图，再配合文字，在自己的电脑上生成一条视频。

本文使用 Windows + ComfyUI + Pika H3 Flex 的本地参考图生成视频（R2V）模板。Pika H3 Flex 基于 MiniMax H3 训练，因此工作流需要 MiniMax H3 基础模型和对应的 Pika 适配文件；ComfyUI 则负责组织和运行整个流程。

本文根据官方资料整理，具体界面、模板和模型文件可能更新。我已在自己的游戏本上跑通 FL2V 和 Pika Flex R2V 工作流；不同工作流和设置的资源需求可能不同。如果页面与本文不同，以 Pika 官方资料和 ComfyUI 的 Pika 模板内说明为准。

一、开始之前：什么叫本地部署？

本地部署就是把运行工具和模型文件下载到自己的电脑，再使用自己电脑的计算资源生成视频。

这里介绍的是本地运行 Pika H3 Flex 的模型和工作流，不是用本地 ComfyUI 节点调用远程视频 API。第一次下载工具和模型需要联网，完成后的实际运行是否全程离线，还要看工作流中有没有使用其他网络服务。

Pika H3 Flex 适配文件基于 MiniMax H3，模型和适配文件有相应使用条件。商用或在特定地区使用前，请查看 Pika 的许可说明和 MiniMax 官方许可。本地生成也会产生设备和电力成本。

二、准备什么？

1. 一台合适的 Windows 电脑

本教程以 Windows 10 或更新版本为例，并使用独立 GPU 运行。请先查看 Comfy Desktop Windows 安装说明及所选模型、驱动和工作流的兼容要求。

模型能否跑起来，不只取决于显卡名称，还与显存、系统内存、模型精度、视频分辨率和时长等有关。目前不能根据这篇概览保证某个显卡一定能跑。如果出现显存不足，也不代表安装步骤一定做错了。

硬件门槛：先看这里

我的电脑是一台 机械革命蛟龙 16 Pro 2025 游戏本，已经在本地跑通了 FL2V 和 Pika Flex R2V 工作流：

配件 我的配置
GPU NVIDIA GeForce RTX 5070 笔记本电脑 GPU，8 GB 显存
内存 32 GB
CPU AMD Ryzen 9 7845HX

我的实际运行说明 8 GB 显存、32 GB 内存的笔记本可以尝试，但这不是官方最低配置，也不能保证所有相同显存的电脑和工作流都能跑通。生成尺寸、时长、模型版本和运行方式都会影响占用与等待时间；本文介绍的参考图模板是否适用于你的环境，还需要自行验证。

显存不足时，部分工作流会把模型数据转移到系统内存，通常需要更多内存和等待时间。可以先从较小画面和较短视频开始尝试；如果仍无法运行，可以考虑在线平台或云服务器。

2. 足够的磁盘空间和网络

本篇使用的模板中，仅基础模型、文本编码器和两个 VAE 文件在核对时就超过 37 GB，还需要额外空间存放 Pika 适配文件、ComfyUI、下载缓存和输出视频。实际大小、文件组合及可用下载渠道会变化，以下载页面和模板提示为准。

3. 四个需要认识的词

  • 节点：工作流中的一个处理步骤，比如读取提示词或保存视频。
  • 工作流：由节点和连接线组成的一套生成流程。
  • 模型文件：模型和相关组件的数据文件，本文常见格式是 .safetensors。
  • 队列：提交后等待执行的任务列表。

不用在第一次使用时弄懂所有节点。先用官方模板生成一条视频，后面再逐个研究。

三、安装 ComfyUI

  1. 打开 ComfyUI 官方下载页，选择 Windows 版本。
  2. 运行下载的安装程序，按照提示完成安装并启动 Comfy Desktop。
  3. 首次配置时，选择在本机安装并运行，按页面提示选择合适的设备和安装位置。
  4. 等待安装和环境准备完成，打开 ComfyUI 画布。

具体安装界面可能变化，遇到问题可对照 Windows 官方安装指南。安装位置和共享模型目录以安装时的设置为准，不必照搬其他教程里的盘符。

注意：Comfy Desktop 可以选择云端或本地。本篇要运行本地模型，应选择本机实例，而不是云端实例。

四、打开 Pika H3 Flex 参考图生成视频模板

  1. 在 ComfyUI 中找到工作流模板库（Template Library）。
  2. 在 Video 分类中查找 Pika H3 Flex Reference to Video / Ref2VA 模板，并打开它。
  3. 如果提示缺少模型文件，可以使用界面提供的下载方式；下载前核对文件名、大小、来源和存储空间。

官方模板也可以从 GitHub 的 Pika H3 Flex Ref2VA 工作流文件下载：打开页面后使用下载按钮保存 JSON，再通过 ComfyUI 的打开工作流功能加载。不要把网页地址直接改成文件扩展名保存。

如果模板找不到或提示节点缺失，先核对 ComfyUI 和模板版本。该模板需要支持对应功能的版本；稳定版、桌面版和开发版的更新进度可能不同。

打开模板后，如果没有自动下载或自动下载失败，可以根据模板里的 Note: Model Links 提示手动下载。下面是核对时的 Ref2VA 模板所列文件，以你实际加载的模板为准：

六、换成自己的参考图并输入提示词

准备两张自己的图片：一张主体清楚的橘猫图，一张办公室场景图。可以使用自己拍摄或制作的图片，第一次尽量选择主体清楚、画面简洁的素材。参考图用于提供外观和场景，生成结果不会保证与原图完全一致。

  1. 在模板中找到 LoadImage (Picture 1 — pilot)，上传橘猫图，替换模板自带的飞行员图片。
  2. 找到 LoadImage (Picture 2 — station)，上传办公室图，替换模板自带的空间站图片。保留图片节点到参考视频节点的连接。

这个示例不要求对白。工作流也可能生成环境声音或音乐，最终以实际结果为准。

七、设置画面并开始生成

  1. 在模板的分辨率设置中选择横屏，例如 16:9。
  2. 第一次建议在 Resolution Selector (Size) 的 megapixels 中改为 0.4 百万像素，并用约 5 秒时长测试；实际画面大小和可选项以模板界面为准。能否运行仍取决于设备和其他设置。
  3. 确认两张自己的图片已加载、连接正确，模型、文本编码器、视频 VAE、音频 VAE 和 LoRA 的下拉框都选中了对应的 Ref2VA 文件。
  4. 确认当前是本地工作流，点击界面中的运行按钮，将任务加入队列。
  5. 等待执行完成。首次加载模型可能较慢，运行时间取决于设备和设置。

核对时的模板通过 ResolutionSelector 设置画幅，SaveVideo 负责保存结果；不同版本的界面可能变化。请保留模板已有的连接，第一次不要同时修改多个高级参数。

八、找到并检查生成的视频

执行完成后，在工作流的保存视频节点查看结果。当前官方模板的保存前缀为 video/Pika_H3_Flex_REF2V，输出通常位于 ComfyUI 配置的 output 目录下的 video 文件夹；桌面版的实际输出目录以本机设置为准。

打开结果，看看：

  • 橘猫的外观和办公室是否参考了上传的图片？深蓝色西装是否出现？
  • 猫是否坐在椅子上，并朝桌面文件的方向看？
  • 阳光和缓慢推进的镜头是否符合预期？
  • 画面有没有明显变形，生成的声音是否合适？

如果结果不满意，保留第一次的视频，再一次只调整一个方向。例如镜头推进太快，可以把最后一句改为“镜头非常缓慢地向前推进”；如果画面杂乱，可以简化场景描述后再试。多次尝试会消耗时间和本机算力。

九、常见问题

模型下拉框里没有文件

检查文件是否完整下载、放在正确的模型目录和子文件夹中，再刷新列表或重启。不同安装方式可能有不同的共享目录；还要核对模板期待的文件名与下载版本是否一致。

提示显存不足怎么办？

先确认报错发生在哪个节点，再检查显存占用、模型版本和设置。可以根据官方模板及模型说明尝试较低分辨率或其他兼容配置；如果设备仍无法运行，可以使用在线平台，或后续考虑云服务器。

模板里有节点缺失

查看启动日志和版本，核对 Pika H3 Flex 官方模板及其说明。桌面稳定版可能晚于开发版获得某些节点；更新前先保存现有工作流和重要数据。

本地视频为什么和在线平台效果不同？

模型版本、提示词处理、分辨率和生成设置都可能不同。Pika 提供的远程服务及高分辨率处理与本地开放权重工作流并非同一个配置；本地速度也取决于硬件和运行方式。

十、下一步

到这里，我们已经按官方工作流梳理了从安装 ComfyUI、准备模型，到上传参考图、输入提示词、生成和检查视频的过程。第一次能否跑通取决于你的环境和硬件；遇到问题时，先保存完整报错信息，再逐项检查。
